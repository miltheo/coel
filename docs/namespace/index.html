Namespace and IRI policy

The COEL namespace provides stable entry points for public documentation, versioned artefacts, model registries, mappings, derived serialisations, and supporting utilities.

Namespace root
https://w3id.org/coel/
Resolution pattern
HTML pages for documents, raw files for artefacts
Versioning

Derived Artefacts

Model Turtle files are derived from canonical CSV registries. Mapping Turtle files are derived from mapping CSV files. Derived TTL files support RDF and machine-processing workflows, but they should not be edited independently of their source CSV files.

Optional Projection Resources

JSON-LD is an optional implementation resource for projecting valid COEL Behavioural Atom JSON payloads into linked-data form. It is not the core identity of COEL v2.0 and does not replace the Atom JSON Schema, canonical CSV registries, or mapping CSV files.

Optional projection resource currently published in the namespace.

Versioning

Public resource paths include explicit versions where artefacts are versioned. Released version paths and stable IRIs should remain resolvable. Changes to registry terms, schema structure, or mapping semantics should be reviewed as release-governed changes and documented with the corresponding release.
