COEL Behavioural Atom v2.0

A COEL Behavioural Atom v2.0 is a JSON object for recording a specific human event relating to an individual participant or environment in time.

Notes

  • An Atom must identify a participant, an environment, or both.
  • The structure is designed to avoid direct personal identifiers.
  • A minimal synthetic Atom example is included at atom/2.0/examples/minimal-atom-example.json; private evaluation payloads are excluded.
  • JSON-LD projection resources are maintained separately and do not replace the JSON exchange format.
