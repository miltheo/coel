Classification of Everyday Living

COEL v2.0 public artefacts

COEL v2.0 provides versioned resources for behavioural event data interoperability: Atom schema resources, CSV registries, mapping CSVs, derived serialisations, and supporting utilities. The live w3id namespace is the primary public entry point for these resources.

Operating Model

Classification model CSV registries are the source of truth for model terms and stable term IRIs. JSON and Turtle serialisations are derived files generated from those CSV registries.

COEL v2.0 is an independent public artefact collection that builds on OASIS COEL v1.0 concepts. It is not an OASIS publication.
