# COEL Behavioural Atom v1.0

Canonical IRI: `https://w3id.org/coel/atom/1.0/`

This folder contains the legacy public resources for **COEL Behavioural Atom v1.0** derived from the original OASIS COEL v1.0 standard.

## Purpose

These resources are provided for reference, continuity, and comparison with later COEL v2.0 developments. They represent the legacy Atom structure associated with the COEL v1.0 standard.

## Notes

- COEL v1.0 is an OASIS standard.
- This folder is included to preserve access to the legacy Behavioural Atom resources.
- Users seeking the extended repository resources developed for the COEL v2.0 ecosystem should refer to `https://w3id.org/coel/atom/2.0/`.
