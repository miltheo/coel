# COEL Model v2.0

Canonical IRI: `https://w3id.org/coel/models/coel/2.0/`

This folder contains the versioned public resources for **COEL Model v2.0**.

## Purpose

COEL Model v2.0 provides the versioned behaviour classification registry used within the COEL ecosystem. It supports consistent classification, lookup, validation, mapping, and reference across Atom payloads and related implementation resources.

## Included artefacts

- `coel-model-v2.0.csv`  
  Tabular registry for COEL Model v2.0.

- `coel-model-v2.0.json`  
  JSON serialisation of the model registry.

- `coel-model-v2.0.ttl`  
  RDF/Turtle serialisation of the model registry.

- `CHANGELOG.md`  
  Change note documenting the correction of duplicate wound care codes inherited from COEL Model v1.0.

## Notes

- This is a versioned model resource.
- COEL Model v2.0 includes corrections to duplicate wound care codes present in COEL Model v1.0.
- Users working with legacy COEL Model v1.0 data should review `CHANGELOG.md` for migration-relevant details.
