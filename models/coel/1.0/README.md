# COEL Model v1.0

Canonical IRI: `https://w3id.org/coel/models/coel/1.0/`

This folder contains the legacy public resources for **COEL Model v1.0** derived from the original OASIS COEL v1.0 standard.

## Purpose

These resources are provided for reference, continuity, and comparison with later COEL v2.0 developments. They represent the legacy COEL behaviour classification model associated with the COEL v1.0 standard.

## Notes

- COEL v1.0 is an OASIS standard.
- This folder is included to preserve access to the legacy COEL Model v1.0 resources.
- Users seeking the corrected and versioned repository resources developed for the COEL v2.0 ecosystem should refer to `https://w3id.org/coel/models/coel/2.0/`.
