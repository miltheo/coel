# COEL Model Resources

Repository path: [models/coel/](./)

This folder contains versioned **COEL classification model resources** within the COEL ecosystem.

These resources provide the versioned registries for the COEL behaviour classification model and support lookup, validation, mapping, and reference across Atom payloads and related implementation resources.

## Included versions

- [1.0/](1.0/)
  Legacy COEL Model v1.0 resources.

- [2.0/](2.0/)
  COEL Model v2.0 resources.

## Notes

- Each model version is organised in its own subfolder.
- Version-specific details are documented within the corresponding subdirectory README files.
- Users should rely on the versioned resources rather than unversioned references.
