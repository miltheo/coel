# ActivInsights Model Resources

IRI: [https://w3id.org/coel/models/activinsights/](https://w3id.org/coel/models/activinsights/)

This folder contains versioned **ActivInsights classification model resources** used within the COEL ecosystem.

These models are implementation-specific resources contributed as part of the broader COEL v2.0 ecosystem and are provided to support validation, mapping, interoperability, and reference.

## Included model families

- [behavioural_bout/](behavioural_bout/)
  ActivInsights Behavioural Bout Model resources.

- [rest_activity/](rest_activity/)
  ActivInsights Rest Activity Model resources.

## Notes

- Each model family is organised using versioned subfolders.
- Model-specific details and artefacts are documented within the corresponding subdirectory README files.
- These resources can be used alongside COEL model registries and mapping files within the wider COEL ecosystem.
